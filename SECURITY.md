# Security Policy

## Supported Versions

Currently, only the latest `master` branch of **NecroSpider** is supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 4.x.x   | :white_check_mark: |
| < 4.0.0 | :x:                |

*Note: Versions prior to 4.0.0 refer to the original SpiderFoot branches. For support regarding older versions, please refer to the original repository.*

## Reporting a Vulnerability

We take the security of NecroSpider seriously. If you discover a security vulnerability within this project, please **do not** open a public issue.

Instead, please privately report the issue by reaching out to the maintainer:
- **Contact**: Reach out to [ch0udharyji](https://ch0udharyji.com) securely.

Please include the following details in your report:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Any potential impact it may have on users.

We will endeavor to acknowledge your report within 48 hours and will work diligently to patch the vulnerability and release a security update.
